## Часть A. Почему так

### A1 — почему изменилось и у `a`

В b копируется ссылка на объект, поэтому a и b указывают на один и тот же объект. Запись b.n = 2 меняет его свойство и через a.n мы читаем уже новое значение

### A2 — почему `3` раньше `2`

Сначала выполняется синхронный код поэтому выводятся 1 и 4. Затем выполняется micro task из .then(), которая выводит 3, а setTimeout() даже с нулевой задержкой создает macro task поэтому он последний отрабатывает и выводится 2

### A3 — почему счётчик остался нулём

У стрелочной функции нет доступа к this она берёт его из внешней области, а вызов counter.add() не привязывает его к counter. Поэтому изменяется не counter.n и остаётся равным 0

## Часть C. Обоснуйте выбор

### C1 — какой вариант карточки и почему

Выберу `<a class="card" href="item.html?id=7">Название</a>`

Почему?
1. Семантически верно и лучше accessability для людей с ограниченными возможностями, могут использовать Tab в качестве навигации
2. Браузер позволяет открыть её в новой вкладке, скопировать адрес или увидеть его при наведении. Переход по href также работает при отключённом JavaScript.

### C2 — какой вариант вывода списка и почему

Выберу
 
```
users.forEach((u) => {
  const li = document.createElement("li");
  li.textContent = u.name;
  list.append(li);
});
```


Почему?
Пользовательское имя вставляется как текст, а не как HTML, что лучше для безопасности от XSS атак, когда вставляют свой JS код
